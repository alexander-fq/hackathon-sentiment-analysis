Endpoints de la API

Host: localhost:8080
Método Endpoint Descripción Scope
POST /api/sentiment Analiza un texto en tiempo real. ANALYZE
GET /api/sentiment/history Recupera el historial de predicciones persistidas. HISTORY
GET /api/sentiment/history/{prediction} Filtra historial por tipo de sentimiento. QUERY
GET /api/sentiment/statistics Estadísticas agregadas del sistema. STATS
POST /api/auth/register Crea un nuevo usuario en el sistema. AUTH
POST /api/auth/login Inicia sesión y obtiene token JWT. AUTH
